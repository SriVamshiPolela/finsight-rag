FinSight RAG

Multi-agent retrieval over real SEC 10-K filings. Ask a question in plain English — a router picks the right specialist, retrieves grounded context, and answers with citations back to the actual filing.

Every example on this page is a real, unedited transcript captured while the system was live on AWS Lambda with a real Claude API key attached. That deployment has since been intentionally retired — an always-on, unauthenticated public endpoint with a billed key attached is a real cost/abuse risk, not a hypothetical one — so this page is now statically hosted and doesn't make live calls. The code, and the exact commands to redeploy it live, are on GitHub.

How it works

One router, four specialists

The LLM proposes an agent and its arguments; deterministic Python retrieves and dispatches. Each agent has a narrow, explicit input schema — not a free-form prompt.

filing_qa

Filing Q&A

Direct question against one company. Search filtered to that ticker.

comparison

Comparison

Metric or disclosure compared across companies or periods.

risk_flag

Risk / Red-Flag

Risk-factor language, surfaced from the filing's Item 1A section.

summarization

Summarization

Executive summary of one section — full coverage, not similarity search.

Proof, not vibes

Measured against a 24-case labeled eval set

Routing accuracy and four RAGAS-methodology metrics — faithfulness, answer relevancy, context precision, context recall — scored by an LLM judge and logged to MLflow.

Run it yourself

Fully open source

Clone it, add your own Anthropic key, and it runs — locally or redeployed to AWS with the same commands used to build this project.

git clone https://github.com/SriVamshiPolela/finsight-rag.git cd finsight-rag && pip install -r requirements.txt cp .env.example .env # add your ANTHROPIC_API_KEY PYTHONPATH=src python -m uvicorn finsight.api.app:app --reload
